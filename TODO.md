# Delivery outcomes

- [ ] **Connection, sign-in and account access:** A typed centralized API client targets the provided `/api/v1` backend, includes cookies, handles inconsistent auth response shapes and both error/message fields, and uses the deployment API URL configured by the user. Require a verified backend session before displaying the workspace; redirect signed-out users to the sign-in page. Provide sign-up, sign-in and sign-out; verify a cached user ID against `GET /users/:id`; clear local user and records and handle unauthorized sessions. No password reset, social login or invented authentication.
- [ ] **Overview and analytics:** Provide overview metrics for total and active subscriptions, upcoming renewals, recent subscriptions, category/status composition and quick actions. Fetch all subscription pages before account-wide totals or client filtering. Normalize frequencies, keep currencies separate without false exchange rates and identify projected recurring cost as an estimate, not transaction history.
- [ ] **Subscription management:** List, retrieve, add, edit, cancel and delete using actual subscription API routes. Support fields name, price, currency, frequency, category, paymentMethod, status, startDate and renewalDate, with only specified enum options; never let the user choose the owner ID. Include search, filtering, sorting, pagination, details, validation, loading/empty/error states and explicit cancel/delete confirmation. Match the response's `data`, `total`, `currentPage` and `totalPages` shapes.
- [ ] **Renewals:** Derive renewal dates, days remaining, amount, frequency and status from the full subscription dataset and sort by `renewalDate`. Do not rely on the defective upcoming API route/filter.
- [ ] **Profile and account:** Show and update name, email and password through `PUT /users/:id`, refresh local profile state and support confirmed account deletion using `DELETE /users/:id` with `{ "confirm": true }`; provide sign-out.
- [ ] **Administrator tools:** Show administration only to admin users. Support list/create/get/update/delete users, selected-user subscriptions and subscription cancellation via real admin routes. Do not allow administrators to delete their own account.
- [ ] **Design and delivery:** Build a modern, responsive React and TypeScript UI with Tailwind CSS v4, accessible interactions, responsive navigation and clear signed-in session states. Document API setup and known backend integration defects. No fabricated notifications, payment processing, analytics endpoints or conversions.
